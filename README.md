# Symmetrical_LDO_Regulator


TL431 based LDO regulators for symmetrical power supply.

&nbsp;

Showcase and Test of discrete symmetrical LDO regulators.

Orders, Assembly and Test in progress.

---

Design specifications:  
  &nbsp;-5 V input  
  &nbsp;-isolated  
  &nbsp;-output current ca. 100 mA per rail  
  &nbsp;-can be USB powered  

---

Motivation:  
Most jellybean LDO regulators offer too high a voltage dropout.  
This constitutes an attempt at building my own regulator, for use in measurement instrumentation.
